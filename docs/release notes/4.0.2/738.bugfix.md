### Enforce Neighbor-ID Uniqueness

**Description**

Asymmetric scoring, such as `A · quant(B) ≠ B · quant(A)`, can assign different scores to the same neighbor, defeating score-local duplicate checks and reducing effective graph degree.

`NodeArray` now checks IDs independently of scores and deduplicates complete candidate merges, retaining existing scores and score ordering. `ConcurrentNeighborMap` also deduplicates initial candidate batches and rejects duplicate offers before copying or changing pruning state.

More distinct edges can improve recall but increase traversal work and reduce QPS at fixed search settings. Results vary by dataset and construction seed.

**How to Enable**

Automatic; no configuration required.

**Notes**

API and index format unchanged. Rebuild existing indexes to regenerate adjacency. Supersedes [#522](https://github.com/datastax/jvector/pull/522).
