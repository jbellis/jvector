### Deferred batch graph serialization

Parallel graph serialization can now write complete layer-zero records in bounded
batches of 64, with an optional positive batch-size override. Grid supplies inline
NVQ or full-precision features during final serialization, after graph cleanup,
and uses buffered vector ranges when the input source supports them.

The core writer accepts application-supplied feature states independently of the
benchmark harness or dataset prefetching. Complete-record batching applies equally
to fully preloaded inputs; the source does not have to preload the whole dataset.

The existing V6 layout, readers, ordinary vector sources, and incremental
`writeFeaturesInline` API remain supported. Prewritten features are preserved.
Concurrent feature suppliers must keep their input source available until writing
finishes. The existing parallel-writer selection remains unchanged.

Recorded construction studies with dataset prefetching reduced ample-memory final
write time from 136.10 to 50.69 seconds on MPNet 10M, 148.50 to 64.02 seconds on
Cohere 10M, and 162.64 to 51.76 seconds on CAP 6M. These are separate fresh runs,
not a universal throughput or memory guarantee. See
[Deferred batch serialization](../../deferred-batch-writer.md) for usage.
