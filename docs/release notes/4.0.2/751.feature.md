Google Highway native SIMD is no longer experimental and is preferred by default
on supported Java 22+ runtimes. `jvector.enable_native_vectorization` is the supported
flag; the former name remains a deprecated compatibility alias.

Successful native selection uses `MemorySegmentVectorFloat` instead of
`ArrayVectorFloat`. Consumers should use `VectorFloat`, or `FloatArray.array()`
when array access is needed; direct casts and assumptions about `get()`'s backing
storage must be updated. `copyFrom` supports both built-in float vector types.
Disable automatic native selection with `-Djvector.enable_native_vectorization=false`
to retain the previous provider choice. Native operations require provider-created
vectors; copying between storage types does not make mixed-storage arithmetic valid.

Pass `--add-modules jdk.incubator.vector --enable-native-access=ALL-UNNAMED`
for classpath deployments. Missing native access can produce JVM warnings; denied
native access or missing required library symbols cause automatic selection to fall
back to the Java provider. Explicitly forcing native fails during initialization.
