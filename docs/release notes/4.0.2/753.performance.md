### Extend Native SIMD Coverage for Vector Operations

**Description**

Move minimum and sum reductions, in-place scaling, vector and scalar subtraction,
and Hamming distance from Panama Vector API fallbacks to native Google Highway
kernels, using the existing x86-64 and AArch64 ISA dispatch.

Subtraction ranges and Hamming input lengths are validated before native calls.
Minimum reduction preserves Java’s NaN propagation and signed-zero behavior.

**How to Enable**

These operations use the existing experimental native-vectorization setting.
No new configuration is required.

**Notes**

No public API or index-format changes.
