### Optional direct I/O for disk indexes

Read immutable disk indexes through Linux `O_DIRECT`, with bounded batched reads
and an optional shared block cache, to avoid depending on the OS index page
cache. Existing disk formats and mapped-reader defaults are preserved.

Enable it with `ReaderSupplierFactory.openDirect(path, ioDepth, cacheBytes)`
on supported Linux systems with JDK 22+ and native access enabled.
See [the reader documentation](../../direct-io-index-reader.md).
